Emberfall Duel — an original turn-based card battler. You are the Ember Apprentice, duelling Sable, the Ash Warden, across a felt table: 30 health each, a mana crystal a turn, a 30-card deck in four suits (Ember, Tide, Leaf, Stone), creatures that take the board and strike, spells that answer them, and Resonance — the second card of one suit played in a turn is stronger. Playable with mouse and keyboard, entirely offline, in any desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and press Play the duel.
